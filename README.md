## ⚡ SUIT SYSTEMS — ACTIVE PROJECTS

> *"The suit and I are one." — Every project I ship is an extension of what I'm thinking.*

<br/>

### 🔊 Hey Orvyn — Wake Word Detection Engine
Custom multilingual wake word detection. **99.4% accuracy**. ONNX export at **0.18ms inference latency**. Built from scratch — no off-the-shelf wake word APIs.
`Python` `ONNX` `TensorFlow` `Signal Processing` `On-Device ML`

---

### 🤖 Agentify — No-Code AI Agent Platform
Drag-and-drop platform to build AI agents without writing a single line of code. Powered by ElevenLabs voice + Sarvam AI for Indic language support.
`Next.js 14` `TypeScript` `Supabase` `ElevenLabs` `Sarvam AI`

---

### 🎙️ ORVYN — Voice-First Android Assistant
A voice-native Android assistant that thinks before it speaks. Jetpack Compose UI, dual-brain architecture with OpenAI + Gemini.
`Kotlin` `Jetpack Compose` `OpenAI API` `Gemini API`
